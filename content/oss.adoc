== Open Source

Open Source Software has shaped my career. Over the years, I've contributed as a maintainer, project leader, conference organizer, and speaker while building tools used by communities and organizations around the world.
Here are some of my contributions.

== Project 

*Updatecli*

Updatecli is an open source automation tool that I created to continuously update software dependencies, infrastructure, and configuration. It automatically opens pull requests when upstream releases occur and has evolved into a universal update policy engine used across multiple organizations.

https://www.updatecli.io[Project Website]

*Jenkins*

https://www.jenkins.io/project/board/#infrastructure[Jenkins Infrastructure Officer]: 2019 -> 2021

As Jenkins Infrastructure Officer, I led initiatives that operated and evolved the services used by the Jenkins community and contributors. I was also involved in project governance and outreach activities.
